# DJ DRIFT'S PINK SLIPS — Lore Bible

The complete world bible for *DJ DRIFT'S PINK SLIPS*, a 1950s emergent RPG drag racing game set in Winterberry Acres, Heartland USA.

Every NPC conversation in the game is generated by DriftGPT, a 691M parameter language model trained from scratch on this lore. The richer this bible, the more alive the world feels.

## Canon vs Draft

Every file has YAML frontmatter with a `status` field:

- **`status: canon`** — Ground truth. Agents treat this as fact. Consistency checks run against it.
- **`status: draft`** — Work in progress. May contain contradictions or placeholders. Agents flag but don't enforce.
- **`status: historical`** — Dead characters or past events. Canon but the NPC is not present in 1959.

If a file has no frontmatter, treat it as draft.

## How to Add a Story

1. Write the story
2. Save to `stories/XX_title.md` with frontmatter (type, status, year, characters, locations)
3. Rate it (targeting 8+/10)
4. Discuss connections to existing lore — which existing NPCs are involved, what changes
5. Weave into NPC files, timeline, and event docs
6. Run Lore Keeper agent to check consistency

## How to Add an NPC

1. Check `characters_index.md` — does a similar character already exist?
2. Create `npcs/token_id.md` with the standard template
3. Add frontmatter (type, status, tier, token)
4. Add to `characters_index.md`
5. Cross-reference relationships in other NPC files (bidirectional)
6. Run Relationship Dynamics agent to check the social web

## How Agents Use This Repo

The 6 agents defined in `agents/` operate on this lore:

| Agent | What It Does | Key Files |
|-------|-------------|-----------|
| **Lore Keeper** | Consistency checks across all files | timeline.md, npcs/, winterberry_acres.md |
| **Character Voice** | Ensures NPCs sound distinct | npcs/ (Voice sections) |
| **Period Accuracy** | No anachronisms, correct 1950s details | All files |
| **Relationship Dynamics** | Checks social web richness | npcs/ (Relationships sections) |
| **Training Data Generator** | Creates fine-tuning examples from lore | npcs/, stories/, events/ |
| **Training Data Advisor** | Reviews training dataset quality | Generated data files |

## The Rule

Every piece of lore must answer: **"Which NPC would talk about this, and in what situation?"**

If no NPC would ever reference it in conversation, it's set dressing, not training data. Write it anyway — it makes everything else more grounded — but know that only lore that becomes dialogue shapes the model.

## Setting

**Winterberry Acres, Heartland USA — 1959**

The player arrives in 1959. All events from 1949-1958 are history discovered through NPC conversations. The town is deliberately unanchored from any real U.S. state.
